## 不在本目录的东西

| 内容 | 位置 | 原因 |

| 工程硬规则（坐标系、真值优先级、熔断纪律、阈值） | [`../AGENTS.md`](../AGENTS.md) | 规则是"怎么做对"，不是"游戏是什么" |
| 失败记录详情 | [`../records/`](../records/) | 失败详情是**历史**，只提炼成规则，不进知识库（不进开源仓库） |
| 依赖图与本轮目标 | [`../plan.json`](../plan.json) | 运行时状态，不是知识 |

## 边界纪律

1. **知识库只写"换个存档依然成立"的东西。** 带具体存档坐标、局数、人名的一律不进；计划文件也不放坐标（AGENTS.md §8）。
2. **失败不写进知识库，只写进规则。** 失败详情放 `records/`；提炼的可执行规则进 `AGENTS.md`；固化成代码。
3. **知识库每条实质性数值必须有出处**；社区经验值明确标注，不与官方机制混淆。
4. 阈值以 `AGENTS.md` 与代码为准；知识库不重复收录，避免两处打架。
5. **文档与代码不符时改文档**；但契约（FAST_SLOW_CONTRACT）与代码不符时**改代码**——契约是唯一权威。
