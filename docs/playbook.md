# 场景手册（Playbook）—— 快速应对各种局面

> 面向 AI agent：每个场景给 "识别信号 → 必做动作 → 严禁动作 → 验证判据"。
> 机制原理见 `knowledge-base.md`，地图分析见 `graph-model.md`。

## 场景 A：开局（cycle 0~2，3 人，封闭洞）

**识别**：`oni observe` 显示 3 人、无制氧设备、氧气单向下降、可达格 ~12。
**顺序（不能换）**：
1. `oni graph` 看生活区气室氧气续航（< 1 周期 = 生死线）。
2. `oni plan` 确认 `survival_node`（N1 挖氧石）被选中。
3. 挖氧石：用 `oni probe` 定位最近的氧石（OxyRock），从下方可达格起一格格铺梯子向上挖它。
4. 打通地表换来无限空气（地表 = 地图最高 Y 附近的开放格）。
5. 之后才是：铜→发电机→存储箱→送煤→打印新人→厕所/床→农业站。
**严禁**：先挖煤；把睡觉时段改成工作；往下挖直井（挖过的格子留碎岩，人下得去上不来）。
**验证**：`loose_min OxyRock ≥ 1kg` → N1 done；`breath_ratio ≥ 0.75`。

## 场景 B：空气恶化 / CO₂ 沉底

**识别**：`judge` 报 air / co2_global / suffocation；`oni graph` 某气室 CO₂ 占比高、氯气标记。
**必做**：往上挖通地表（永久换气）；CO₂ 比氧气重会沉底，别让人长期待坑底；用透气砖/打通天花板让气体扩散。
**严禁**：往 CO₂ 坑底继续深挖；只靠制氧机不解决 CO₂ 堆积。
**验证**：`breath_ratio` 回升到 0.75+；生活区气室 `hazards()` 清空。

## 场景 C：卡住（连续多轮零进展）

**识别**：日志"连续 3 轮零进展 → 熔断"；材料/建筑/人口/空气比例都没变。
**必做**：检查 `plan.json` 的 blocked 节点；确认不是保命节点被熔断；换方案而非加轮次。
**严禁**：对着同一条死命令重复 30+ 轮。
**验证**：`oni plan` 有可执行目标；进展指纹变化。

## 场景 D：建造失败（"指令 ok 但没人干活" / "落地失败"）

**识别**：`oni build` dry-run 报 `Unsupported map cell transitions` 或预检不过。
**必做**：
- 梯子/无材料建筑：确认 token 是 `Prefab:7`（无悬空 `#`），由 `build_token` 生成。
- 检查预检三关：占格空、支撑实心（y-1 整条底边）、落脚点在官方可达域。
- 材料必须在该建筑的 `availableMaterials` 白名单里。
**严禁**：绕过预检强下工单。
**验证**：dry-run OK 后再 apply；复读 cell 文件确认建筑出现。

## 场景 E：依赖图死锁

**识别**：日志"依赖图里没有可执行目标"刷屏。
**必做**：`decide()` 在无任何可选节点时复活所有 blocked 节点（`revived`，需写回 todo）；检查 `plan.json` 是否有整条链被熔断。
**验证**：`oni plan` 输出非空目标。

## 场景 F：人口告急 / 有人倒下

**识别**：`no_population` / `population_dropped` / 呼吸 < 35。
**必做**：紧急态占空比（冻 20s 取快照 → 跑 120s 让人自救）；人口为 0 时代理完全停手（别在死图刷工单）。
**严禁**：人口归零还继续挖矿。
暂停语义：AI 开启时**除 `oni hold` 外**的所有暂停 owner——含用户手动 `oni pause`——都会被代理
自动恢复并开施工窗口；唯一受保护的停止信号是 `oni hold`。要真正停住请用 `oni hold`。
**验证**：人口稳定；呼吸回升。

## 场景 G：新局开局设置

见 skill `oni-mcp-opening-setup`：思考前暂停、错峰日程、按属性重命名复制人、禁用自动消毒、侦察起始星体。
