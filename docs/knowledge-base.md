# 《缺氧》(Oxygen Not Included) 机制知识库

> **本文只收录通用知识**：跨存档、跨局面都成立的《缺氧》游戏机制与策略。
> 不含本项目的失败过程记录、不含本项目的存档专属坐标、不含本项目的判定阈值
> （那些属于 `AGENTS.md` 的工程硬规则与 `docs/playbook.md` 的场景手册）。
>
> 每条写「规则 → 落地 → 陷阱」。**事实性数字标注出处**；攻略经验标 [经验]，与官方机制区分。

## 1. 氧气与换气

**规则**
- 复制人呼吸消耗氧气并呼出 CO₂。耗氧 **100 g/s = 60 kg/周期**。[官方: Duplicant](https://oxygennotincluded.wiki.gg/wiki/Duplicant)
- 氧气比 CO₂ **轻**，会向上浮；CO₂ 沉在底部。[官方: Oxygen](https://oxygennotincluded.wiki.gg/wiki/Oxygen)
- 每格气体低于 **50 g 不可呼吸**；50~300 g 可呼吸但会增加复制人压力。[官方: Oxygen](https://oxygennotincluded.wiki.gg/wiki/Oxygen)
- 气体扩散填满所有**正交连通**的开放格；液体不与气体混合，气液分层（气在上、液在下）。[官方: Gas](https://oxygennotincluded.wiki.gg/wiki/Gas)
- 气体在低于凝点 3°C 时冷凝为液体；液体在高于凝点 3°C 时蒸发。[官方: Gas](https://oxygennotincluded.wiki.gg/wiki/Gas)

**落地**
1. 封闭空间里氧气只减不增 → 早期必须做出产氧或换气动作，别等氧气总量掉下来。
2. 挖通地表 = 无限新鲜空气，是最省心的永久换气方案。
3. 产氧用藻类箱过渡（不吃电），中期转电解器（吃电耗水）。
4. 评估空气看**比例**（O₂ vs CO₂）而不是只看氧气总量：氧气总量够但 CO₂ 占比高一样会中毒。

**陷阱**
- CO₂ 沉底坑：往下挖出的竖井底部会积 CO₂，别让复制人长期待在坑底作业。
- 只产氧不排 CO₂：氧气够了但 CO₂ 占比仍高，复制人照样窒息。
- 藻类箱只是过渡：藻类储量有限，中期耗尽会断氧。[经验](https://www.allinwondergame.com/news/oxygen-not-included-beginner-guide)

### 产氧建筑对比
| 建筑 | 输入 | 输出 | 特点 | 出处 |
|---|---|---|---|---|
| 藻类箱 Algae Terrarium | 藻类 30 g/s + 水 300 g/s | 氧气 + 清除部分 CO₂ | 不吃电；直射光下效率 +10%；产物 30°C；无最大压力上限 | [官方](https://oxygennotincluded.wiki.gg/wiki/Algae_Terrarium) |
| 电解器 Electrolyzer | 水 1000 g/s + 电力 | 氧气 + 氢气 | 长期方案；耗水量大，需提前规划水源 | [官方](https://oxygennotincluded.wiki.gg/wiki/Electrolyzer) |

## 2. 温度与热量

**规则**
- 设备运转发热；热量在固体中传导、在气体和液体中对流。[官方: Gas](https://oxygennotincluded.wiki.gg/wiki/Gas)
- 藻类箱产物温度 **30°C**（输入更热则更高）。[官方: Algae Terrarium](https://oxygennotincluded.wiki.gg/wiki/Algae_Terrarium)
- 温度是隐形杀手：发热设备密集布置会让局部温度飙升，影响复制人健康与设备运行。[经验](https://www.allinwondergame.com/news/oxygen-not-included-beginner-guide)

**落地**
- 发热设备分散布置；用墙/地板把产热区隔开。
- 早期局部降温可用冰；后期用冷却液循环、氢室法等。[经验](https://kirokiro.cc/?p=69860)

**陷阱**
- 电解器产出的氧气温度高，直接送进居住区会升温。
- 高温区种不出食物；低温区会让气体冷凝改变布局。

## 3. 电力

**规则**
- 人力发电机消耗煤产电；电池储电，电线输电；设备欠电会停机。[官方: Manual Generator](https://oxygennotincluded.wiki.gg/wiki/Manual_Generator)
- 煤电与气电会产生大量 CO₂，建议单独房间隔离。[经验](https://kirokiro.cc/?p=69860)

**落地**
- 早期电力链：煤 → 存储箱 → 发电机（自动取料）→ 电线 → 用电器。
- 发电量必须匹配总负载并有电池缓冲，否则一断电连锁停机。

**陷阱**
- **建好发电机 ≠ 在发电**：必须有燃料且有人操作才会产出电力。
- 发电的电没有去处（无负载/无电池）等于浪费。
- 关键设施掉电等于慢性死亡：打印舱掉电 = 断掉新人来源。

## 4. 水与液体

**规则**
- 液体受重力影响向下流，会淹没下方区域。[官方: Gas](https://oxygennotincluded.wiki.gg/wiki/Gas)
- 藻类箱需要持续供水，且要定期清理污染水。[官方: Algae Terrarium](https://oxygennotincluded.wiki.gg/wiki/Algae_Terrarium)

**落地**
- 挖穿含水层前先规划排水路线；把取水点放在低处。
- 电解器耗水 1000 g/s，先确认水源供给能力再上电解器。

**陷阱**
- 液体格不是障碍物：建筑可以直接建在液体上，ONI 会把液体挤开（但会改变水流）。
- 污染水需净化或被藻类箱消耗，否则产生污染氧。

## 5. 食物与种植

**规则**
- 复制人通过进食获得热量（kcal）；野生采集只能撑过开局，长期要靠种植/养殖。[经验](https://evagamestation.com/2026/02/28/oxygen-not-included-beginners-guide/)
- 人口增长速度不能超过食物生产速度，否则形成粮食赤字。[经验](https://www.allinwondergame.com/news/oxygen-not-included-beginner-guide)

**落地**
- 前期采集顶住需求，随后建农业站种米虱木（Mealwood）等作物；需要种子 + 浇水 + 光照。
- 食物来源要提前排期：新增人口前先确认食物链能负荷。

**陷阱**
- 断粮是**慢死**：等察觉时往往已经晚了，要按消耗速率预估剩余周期。
- 烘焙/烹饪会改变食物热量与品质，不能只看原始食材。

## 6. 设施与士气

**规则**
- 复制人膀胱满了会在地上排泄，掉落士气并降低工作效率；床位不足导致休息质量差；装饰提升心情。[经验](https://evagamestation.com/2026/02/28/oxygen-not-included-beginners-guide/)
- 打印舱（Printing Pod）是唯一的新人来源。[官方: Printing Pod](https://oxygennotincluded.wiki.gg/wiki/Printing_Pod)

**落地**
- 必备：厕所 + 洗手盆 + 每人一张床位。
- 复制人需要睡觉周期：**不要把睡觉时段改成工作**，复制人永不休眠会累瘫。[经验](https://kirokiro.cc/?p=69860)

**陷阱**
- 士气/疲劳问题会**全 colony 效率下降**，表现为"每个人都在但什么都不快"，容易被误读成卡住。
- 打印舱供电中断 = 永远没有新人，殖民地无法扩张。

## 7. 建造与地形规则

**规则**
- 梯子（Ladder）的建造规则为 `Anywhere`：可悬空、可贴在墙上（竖井就是墙上贴梯子）。[官方: Ladder](https://oxygennotincluded.wiki.gg/wiki/Ladder)
- 建筑有占格（footprint）与支撑要求：支撑在建筑**下方**，宽度大于 1 格时需要**整条底边**都有支撑。[官方: Building](https://oxygennotincluded.wiki.gg/wiki/Building)

**落地**
- 竖井挖掘：从下方可达格开始一格格往上铺梯子，复制人攀爬着逐层开挖。
- 建造前先确认目标占格为空、底边有支撑、附近有复制人走得到的落脚点。

**陷阱**
- **直挖深井会把人困死**：复制人向下移动是自由落体，挖出的竖井底部没有地板就爬不回来。
- 挖过的地方会留下碎岩，导航视为阻挡 → 必须先清扫（sweep）清障，否则挖掘工单会被立刻取消。
- 往上移动必须有梯子（当前格或目标格），不能凭空攀爬；斜向上是"上台阶"，要求目标正下方是实的。

## 8. 印刷舱与新人

**规则**
- 打印舱定期提供奖励（新人、材料包、种子），是唯一的新人来源。[官方: Printing Pod](https://oxygennotincluded.wiki.gg/wiki/Printing_Pod)

**落地**
- 定期领取打印舱奖励；把它接进电力网络并保护其供电线路。

**陷阱**
- 打印舱被建筑压住或断电 = 永远没有新人。
- 打印舱周边是保护区，不要在其占格上叠加建筑。

## 9. 风险清单（死法速查）

| 死法 | 早期信号 | 预防动作 |
|---|---|---|
| 窒息 | 可呼吸比例持续下降、呼吸值偏低 | 先产氧/换气；看比例不看总量 |
| CO₂ 沉底 | 竖井底部 CO₂ 堆积、复制人反复"寻找安全区域" | 别挖直井；打通顶部换气；让人离开坑底 |
| 饿死 | 食物储备持续下降 | 早建农业站；控制人口增速；按速率预估 |
| 士气/疲劳崩 | 压力普遍偏高、效率普降 | 厕所/床位/装饰；保留睡眠时段 |
| 断电 | 关键设施停机 | 燃料链 + 电池；保护供电路径 |
| 困死/塌方 | 挖掘目标下方悬空、没有退路 | 预检拦悬空下挖；用梯子列做退路 |

## 10. 建造与材料的硬规则（2026-11-21 实测，最易踩）

**规则**
- 建造通道唯一：`world_editor command=edit path=/active/map/viewport.md`，
  token 格式 `PrefabID:优先级#MaterialID`（例：`Ladder:7#Wood`）。优先级必须 1–9。
- **材料必须合法**：mod 只接受该建筑 `materialCategories` 类别内的材料。
  梯子 = `BuildableRaw`（藻类/砂岩/泥土…）或 `BuildingWood`；砖块 = `BuildableRaw`；
  人力发电机/电线 = `ZincOre`。
- **一次只能下一条工单**：mod 明确 `Operation edits support exactly one executable command`
  （游戏变更非事务性）。

**落地**
1. 建造前先查 mod 的权威答案：`oni://buildings/materials?prefabId=<Prefab>`。
   它按**地上实际库存**返回可用材料；没有则返回 `autoMaterialReason`。
2. 目录里的 `availableMaterials` **开局是空数组**，`defaultMaterials` 只是**首选一种**
   （梯子 = Isoresin 异构树液），**都不是**可用材料清单。
3. 没有建材时**不要硬造**：mod 会返回 `phase: failed` + `reportedActions: 0`，
   报错看不出原因，看起来像"指令 ok 但没生效"。正确做法是**先去采建材**。

**陷阱**
- 开局地上通常**零建材** → 梯子/砖块/发电机/存储箱全部造不了。
  梯子要 `Isoresin`（异构树液，来自植物）或藻类/木头 —— 通常需要先挖通通道采集。
- 造 **1 格**梯子（不是 1 段）→ 复制人爬上去 → 再挖头顶 → 再造 1 格 → 一格格往上。
- 地图 token 里 `.` = 空/无视图，`?` = 未知（不是空！），`x` = 氧气，`真` = 真空。
- 建筑锚点会偏移（地图渲染 vs 建筑索引不一致）→ 关键建筑留 1 格缓冲。
### 开局通用流程（实测得出，换存档同样适用）

**规律**：开局地上**零建材** → 梯子/砖块/发电机/存储箱**全部造不了** →
所以**第一步不是挖矿、也不是挖氧石，是先挖通一条通道拿到建材**。

**通用顺序**
1. 观察：`oni observe` + `oni graph --full` + `oni probe` 找最近的**可采集建材**（藻类 Algae / 泥土 Dirt / 植物）。
2. 挖通通道：从复制人**当前可达区**挖到建材格（每轮只挖 1 格，靠前沿语义推进）。
3. 确认材料到位：`oni://buildings/materials?prefabId=Ladder` 应返回 `autoMaterial: <某材料>`
   （开局时是 `no currently available material`）。
4. 铺梯子列 → 挖氧石（产氧）→ 打通地表（永久换气）。
5. 有了材料再发电、盖房、种地。

**陷阱**
- **梯子列是 1 格 1 格往上**：`auto_ladder` 会在"目标正下方那格的支撑格 (x, y-2)"自动铺梯子。
  铺 1 格 → 人爬上去 → 挖头顶 → 再铺 1 格 → 循环。
- 梯子建好后**复制人可达格数会暴涨**（实测 13 → 49），这是竖井打通的信号。
- 挖开的竖井如果正上方是 CO₂ 空腔，CO₂ 会**往上飘**（比氧气轻的是氧气，CO₂ 重会沉底 ——
  但空腔在上方时，挖开后连通处 CO₂ 会往下走，要留意坑底）。
### 资源循环的最小闭环（实测跑通）

**规则**：殖民地活下来只需要三样材料 + 两个建筑，按这个顺序就能活：

| 材料 | 用途 | 来自 |
|---|---|---|
| 砂岩 / 藻类 | 梯子、砖块、存储箱（BuildableRaw） | 挖开的岩层 |
| 铜矿 | 人力发电机（ManualGenerator） | 铜矿脉 |
| 泥土 | 藻类箱（Farmable）、铺路 | 泥土层 |
| 煤 | 发电机燃料 | 煤层 |

**落地顺序**（实测可跑通的最小闭环）
1. 挖通一条竖井 → 顺便挖到砂岩 → **有建材**（梯子能造了）
2. 铺梯子列往上 → 挖到**氧石** → 持续产氧（开局第一位死因是空气）
3. 找**成簇**的资源层（煤/铜/土在同一片区域最好）→ 一次横挖拿走三种
4. 造**人力发电机**（铜）→ 送煤 → 净 400W（实测确认）
5. 造**藻类箱**（泥土/藻类）→ 不吃电就产氧
6. 打通地表 → 永久换气

**陷阱**
- **资源必须成套拿**：只挖到煤就让"发电机"节点放行 → 但铜矿还没到手 → 建造失败 → 循环卡死。
  用多条件判据（`loose_multi_min`：煤+铜+土 同时达标）再放行下游。
- **梯子很费料**：约 100kg/格。挖 9 格梯子到地表要近 1 吨建材 —— 先在资源富集区横挖，别急着开长竖井。
- **复制人睡觉时不会挖矿**：看起来像"卡住"其实是作息。判定空跑要看**有没有待办工单**，
  不要只看"当前空闲"（且建筑施工中的等待也不算空跑）。
### 判"危险"要看人的状态，不是全局比例（★ 2026-11-21 踩坑）

**规则**：
- **呼吸危险**看复制人**实际呼吸值**（< 35 是危险），不看全局 O₂/CO₂ 比例。
- CO₂ 比氧气重 → 沉在坑底。全局比例被坑底的 CO₂ 拉低，但人住在上层空腔、呼吸 100% ——
  此时**不危险**，只是"该换气"。
- 3 个人的殖民地 CO₂/O₂ > 1 是常态（人呼吸就产 CO₂，密闭空间必然累积）。

**落地**
| 观察到的 | 正确判定 |
|---|---|
| 有人呼吸 < 35 | **危险** → 立刻救援/换气 |
| 比例低但人人呼吸正常 | **行动项**（该换气），不是危险 |
| mod 报 suffocationRisk != nominal | **危险**（mod 的权威判断） |
| 观察源读取失败导致 dupes 为空 | **数据不可信** → 不判"人口为 0"，继续施工 |

**陷阱**
- 误判成危险 → 代理进入紧急态（冻 20s → 跑 120s 循环）→ **施工节奏被腰斩**，
  换气反而更慢（越急越慢）。
- 观察源 MCP 503 时 dupes 列表为空 → 误判"人口为 0" → 代理**完全停手** → 工地全停。
  判定人口前必须先确认 dupes 数据没读失败。
### 污染水与倒地（★ 2026-11-21 全灭事故的通用机制）

**规则**
- **污染水（DirtyWater / 污染氧）不可呼吸** —— 复制人泡在里面等于溺水，
  呼吸值会掉到 0 并**失去行动能力**。
- **失去行动能力（倒地）的复制人不会执行任何差事** —— 他不会去挖矿、不会去建造、
  不会去吃饭。环境不改善，他就会死。
- 固体污染物（污染土 ToxicMud、污染氧 ContaminatedOxygen）会缓慢从所在地扩散。

**落地**

- 看到复制人泡在污染水/污染氧区 → 先 `擦`（mop）排掉污染物，再谈别的。
- 看到复制人「失去行动能力」→ **救援模式**：排毒 / 拖到有空气处 / 治疗，普通施工全部让位。
- 呼吸值读不到（观察源失败）→ **保守判危险**，不要因为读不到就认为安全。

**陷阱**

- CO₂ 会**沉在底部**、O₂ **浮在上面** → 往下挖只会挖进更多 CO₂；
  要改善空气，往**开阔处/高处**挖通，或者直接把外部空气引进来。
- 气体会**逐格扩散**，挖开一个洞后氧气不会瞬间灌满 —— 需要开够大的通路，或把
  复制人挪到已经有氧气的格子。
- 排污染水的工单语法：`擦 @(x,y):9` —— **必须带括号**，且一次只能一条工单。
### 气体分层与密闭空间（★ 2026-11-21 全灭的通用机制）

**规则**
- 氧气比 CO₂ **轻** → 往上升；CO₂ 沉在底部。
- 气体**逐格扩散**，且每格的气体质量独立演化 —— 挖开一个洞后氧气**不会瞬间灌满**。
- 复制人的呼吸值反映的是**所在格**的可呼吸性：格内 O₂ 低于 **50g 不可呼吸**；
  50~300g 可呼吸但加压力。

**落地**
- 评价空气不能只看全局比例 —— 要看**人所在的那几格**。全局比例低但人人呼吸 100%
  = CO₂ 沉在坑底，人暂时安全（该换气，但不致命）。
- 改善空气要往**开阔处/高处**挖（O₂ 在上），别往深处挖（深处只有更多 CO₂）。
- 要让氧气真正涌进来，需要开**够大的通路**，而不是一个小洞。

**陷阱**
- 挖出的通道会把两个气室**连通** —— 好处是空气互通，坏处是**污染也会互通**
  （污染水/污染氧会顺着通道扩散）。开路之前先想清楚两头是什么。
- 长期开着的深竖井是 CO₂ 的"烟囱"：CO₂ 沉底、地表空气灌进来，
  但如果竖井不通地表，CO₂ 会一直在坑里累积。

## 9. 开局竖井与"上不去"的房间

**规则**
- 复制人**向上移动只有两种方式**：目标格**正下方是实心岩**（可以斜着踏上岩肩），
  或目标格/当前格**有梯子**。[官方: Duplicant]
- 气体只沿**正交**方向扩散；对角相连的两格之间不换气。
- 挖开的格子若只与外界**对角**连通，里面是**真空**（Vacuum），不可呼吸。

**落地**
1. 开局若出生在一格高的走廊里（官方可达集只有一行），上方的大气室**走不上去**：
   唯一能上去的位置是走廊两端（那里正下方是实心岩，可斜踏上岩肩）。
2. 往上挖的正确形态是**垂直 + 梯子链**（每格与正下方正交连通 → 有气），
   或**沿实心岩肩的阶梯**（每步的落脚格正下方都是实心岩）。
3. 梯子放在**复制人当前所在的格**：站在梯子格上就能再往上爬一格。

**陷阱**
- **斜着挖出来的台阶会变成真空袋**：只与前一步对角连通 → 复制人走进去呼吸 0，
  后续挖掘工单全部卡住（表现为"没有复制人走得到的落脚格"）。
- **1 格宽的竖井是 CO₂ 陷阱**：CO₂ 沉底且竖井不与外界连通 →
  复制人在井底作业呼吸一路掉到 0。要么挖成 2 格宽，要么让居住区远离井底。
- **倒地的复制人必须挪到床上才能醒**，而"救援"若默认把人送到**基地低层**（毒气区），
  救援就变成了杀手 —— 目标应优先选高处/富氧区的建筑。
